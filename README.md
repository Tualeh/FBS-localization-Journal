# FBS-localization-Journal
Contains ns-3 simulation information, a method for locating FBS in Mathematica and Python and simulated datasets


GitHubMathematicaHP.txt contains Mathematica code for computing half-plane scores.
ScoringEfficient.ipynb contains python code for computing the convex hull scores.
GitHubTimeIntervalMathematica.txt contains Mathematica code for computing time window based FBS localization.

The order of running these files is first GitHubMathematicaHP.txt, then ScoringEfficient.ipynb and finally GitHubTimeIntervalMathematica.txt
